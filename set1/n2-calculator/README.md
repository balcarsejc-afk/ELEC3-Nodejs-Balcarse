# N2 Modular Calculator

Run examples:
```bash
node index.js add 8 4
node index.js subtract 8 4
node index.js multiply 8 4
node index.js divide 8 4
node index.js average 8 4
node index.js divide 8 0
node index.js power 8 4
```
The `operations.js` module exports calculations, `formatter.js` formats the result, and `index.js` reads command-line arguments.
