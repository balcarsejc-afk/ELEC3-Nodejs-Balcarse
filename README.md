## About the Repository

Welcome to the **ELEC3 – Node.js Activities Repository**. This repository contains programming exercises, laboratory activities, source codes, documentation, and screenshots completed as part of the ELEC3 subject.

The activities focus on developing practical programming skills using **JavaScript and Node.js**, including basic Node.js setup, mathematical operations, file management, HTTP server development, API creation, and middleware implementation.

The repository is organized into three branches: `main`, `set-1`, and `set-2`. Each branch serves a specific purpose to keep the activities organized and easy to access.

## Learning Objectives

This repository aims to:

- Understand the fundamentals of Node.js and its runtime environment.
- Learn how to create and execute JavaScript programs using Node.js.
- Apply functions, modules, and basic programming concepts.
- Perform mathematical operations through a calculator application.
- Practice file system operations such as reading and writing files.
- Understand how to create and manage HTTP servers.
- Develop basic API endpoints and handle HTTP requests.
- Understand and implement middleware in server applications.
- Improve programming, debugging, and problem-solving skills.

## Requirements

Before running the activities, make sure you have installed:

1. [Node.js](https://nodejs.org/)
2. npm (included with Node.js)
3. [Visual Studio Code](https://code.visualstudio.com/) or another code editor.
4. Git (for cloning and managing repository branches).

## How to Clone the Repository

Open Command Prompt or your terminal and execute:

```bash
git clone https://github.com/balcarsejc-afk/ELEC3-Nodejs-Balcarse.git
```

Navigate to the project folder:

```bash
cd ELEC3-Nodejs-Balcarse
```

## How to Access Each Branch

To view the main branch:

```bash
git checkout main
```

To access Set 1:

```bash
git checkout set-1
```

To access Set 2:

```bash
git checkout set-2
```

To display all local and remote branches:

```bash
git branch -a
```

## How to Run the Activities

1. Open the repository folder in Visual Studio Code.
2. Switch to the branch containing the activity you want to run.
3. Navigate to the corresponding activity folder.
4. Open the terminal inside that folder.
5. Execute the appropriate Node.js command.

For example, to run the first activity:

```bash
cd set1/n1-setup
node index.js
```

For activities that require npm dependencies, install them first:

```bash
npm install
```

For other activities, navigate to their respective folders and run the appropriate JavaScript file:

```bash
node index.js
```

or:

```bash
node server.js
```

Refer to each activity's individual `README.md` for its specific instructions.
